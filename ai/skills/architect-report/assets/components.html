Copy the markup of a block into a report. The stylesheet and the script are the same as in report.html. Each block names the question it answers; use it only for that question.

State and attention

Note

A remark tied to the block next to it. One tone per meaning: plain for context, amber for a risk, red for a fault, green for a confirmed result, blue for a pointer.

Checkout API is the only caller of the payment provider.

Risk. A late success plus a retry could charge twice.

Fault. Orders in Failed are never retried again.

Confirmed. A declined charge stores nothing.

See also. The retry policy lives in the queue worker.

Badge

A state or a category next to the thing it describes. One per row. Never for ordinary metadata.

Gauge and progress

A gauge is a ratio against a fixed maximum, such as cache hit rate or quota used. A progress bar is work with a known total.
